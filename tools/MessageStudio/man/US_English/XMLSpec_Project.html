MessageStudioProject Element (Root Element)

Declaration

<?xml version="1.0" encoding="utf-8" standalone="yes"?>
<MessageStudioProject Format="1.1" xmlns="nintendo:msgstudio">
	...
</MessageStudioProject>

Description

The MessageStudioProject element is the root element for project files. This element has the following attributes.

Attribute NameDescription
xmlnsXML namespace. This value is always nintendo:msgstudio.
FormatProject file format version. This version is for the project file format itself, and may differ from the MessageStudio software version. The current version is 1.0.

The MessageStudioProject element is the root element, containing all the elements below as child elements.

PluginInfo Element

Declaration

<PluginInfo
	PluginDir="&(ProjectDir)\plugins"
	Recursive="True"> />

Description

The PluginInfo element contains information about the location of plug-ins. This element has the following attributes.

Attribute NameDescription
PluginDirThe name of the directory where plug-ins are located. MessageStudio attempts to load plug-ins from this directory. Macro strings can be used here.
RecursiveSpecifies whether to attempt to recursively load plug-ins located in the subdirectories of the directory indicated by the ProjectDir attribute. Can be set to "True" or "False."

Contents Element

Declaration

<Contents>
	<Directory Name="System">
		<ContentItem Name="Errors.mstxt">
		<ContentItem Name="Items.mstxt">
		...
	</Directory>
	<Directory Name="Test">
		<Meta Key="F4CD8CBE-4A0C-4d3f-BA69-BD1C25B8DC2A">
			*.mstxt
		</Meta>
		<ContentItem Name="Test0.mstxt">
		...
	</Directory>
	...
	<ContentItem Name="Readme.txt">
	...
</Contents>

Description

The Contents element contains information about the content files managed by the project file.

The Contents and Directory elements can each contain ContentItem and Directory child elements. Directory and ContentItem elements both have a shared "Name" attribute. The Name element holds either the directory name or the file name.

The Contents, Directory, and ContentItem elements may all contain "Meta" child elements. The Meta element has just a single attribute named "Key", which contains a GUID to uniquely identify the metadata plug-in. The string contained in the Meta element can be any value set by the metadata plug-in. MessageStudio itself does not do anything with this value. All processing is handled by the metadata plug-in.

Properties Element

Declaration

<Properties>
	<PreBuildEvent>echo hello world</PreBuildEvent>
	<PostBuildEvent>echo good bye</PostBuildEvent>
	<TeamSettings
		AutoUpdate="False"
		AutoCommit="False"
		AutoCloseOnAutoUpdate="False" />
</Properties>

Description

The Properties element contains information about project settings. This element has the following child elements.

ElementDescription
PreBuildEventDescribes any pre-build processing. The shell commands encoded here are run before building. Macro strings can be used here.
PostBuildEventDescribes any post-build processing. The shell commands encoded here are run after building. Macro strings can be used here.
TeamSettings Contains settings for the team management features. This element has the following attributes.
Attribute NameDescription
AutoUpdateCan be set to "True" or "False." If "True," the project updates automatically whenever it is opened.
AutoCommitCan be set to "True" or "False." If "True," a message is displayed when the project is closed, prompting the user to commit any files not yet committed.
AutoCloseOnAutoUpdateCan be set to "True" or "False." If "True," the Update dialog box is closed automatically after updating, provided there were no errors. This is used when the AutoUpdate attribute is set to "True."

Language Element

Declaration

<Language
	LanguageName="JP_Japanese"
	OutputBinary="True"
	ReviewEnabled="True"
	RubyWarning="True"
	SpellEnabled="False"
	Dictionary="en_GB">
	<Language
		LanguageName="US_English"
		OutputBinary="True"
		ReviewEnabled="False"
		RubyWarning="False"
		SpellEnabled="True"
		Dictionary="en_US">
		...
	</Language>
	...
</Language>

Description

The Language element contains information about language settings. The Language element can contain other Language elements as children. These Language element parent-child relationships are loaded directly into MessageStudio as language trees.

Attribute NameDescription
LanguageNameLanguage name.
OutputBinaryCan be set to "True" or "False." If "True," indicates that the builder should output text data and other data for this language.
ReviewEnabledCan be set to "True" or "False." If "True," enables the review features.
RubyWarningCan be set to "True" or "False." If "True," the builder will issue a warning when building the text for this language if any included kanji do not have ruby (furigana) tags. Note that you must not enable this feature for Chinese. (If you do, a warning is issued for every single character.)
SpellEnabledCan be set to "True" or "False." If "True," the spell check features are enabled for this language.
DictionaryName of the spell check dictionary.

Fonts Element

Declaration

<Fonts>
	<FontSetting
		FontName="MyFont"
		Loader="e5d705a4-ee19-4b1c-a3da-eccc4ed6fdf8">
		<FontPath>$(ProjectDir)\..\Font\MyFont.brfnt</FontPath>
	</FontSetting>
	...
</Fonts>

Description

The Fonts element contains information about font settings. The Fonts element contains zero or more FontSetting child elements.

FontSetting Element

The FontSetting element has the following attributes.

Attribute NameDescription
FontNameFont name.
LoaderGUID indicating the font loader plug-in used to load the font resource.

As shown by the FontType element in the Declaration example above, the FontSetting element can also contain user-defined elements. These elements can be added by the font loader plug-in specified in the Loader attribute. MessageStudio itself does not directly process these elements.

Styles Element

Declaration

<Styles>
	<StyleClass StyleName="MyStyle">
		<Default
			RegionWidth="400"
			LineNum="3"
			FontName="MyFont_A"
			RenderMode="f23e335b-192a-4a51-87f8-2ca98cac9a57">
			<Nw4rTextWriter
				ScaleH="1"
				ScaleV="1"
				LineSpace="0"
				CharSpace="0"
				TabWidth="4"
				EnableFixedWidth="False"
				FixedWidth="0" />
		</Default>
		<Substitute
			Language="JP_Japanese"
			RegionWidth="410"
			LineNum="4"
			FontName="MyFont_B"
			RenderMode="f23e335b-192a-4a51-87f8-2ca98cac9a57"/>
			<Nw4rTextWriter
				ScaleH="1"
				ScaleV="1"
				LineSpace="0"
				CharSpace="0"
				TabWidth="4"
				EnableFixedWidth="False"
				FixedWidth="0" />
		</Substitute>
		...
	</StyleClass>
	...
</Styles>

Description

The Styles element contains any style settings. The Styles element may contain zero or more StyleClass child elements.

StyleClass Element

The StyleClass element has only one attribute.

Attribute NameDescription
StyleNameStyle name.

The StyleClass element also contains one Default element and zero or more Substitute elements. Default elements and Substitute elements have almost the same format. These formats are described below.

Default and Substitute Elements

Attribute NameDescription
LanguageName of the language for which these style settings are customized. This attribute is only present in the Substitute element.
RegionWidthWidth of the displayable region. Specified in pixels.
LineNumNumber of displayable lines.
FontNameFont name.
RenderModeGUID indicating the rendering method plug-in used by this style. (See the Rendering Methods Overview for details.)

As shown by the Nw4rTextWriter element in the Declaration example above, both the Default and Substitute elements can also contain zero or more user-defined elements. These elements can be added by the rendering method plug-in specified in the RenderMode attribute. MessageStudio itself does not directly process these elements.

Colors Element

Declaration

<Colors>
	<Color Name="Red" R="255" G="0" B="0" A="255" />
	<Color Name="Blue" R="0" G="0" B="255" A="255" />
	...
</Colors>

Description

The Colors element contains zero or more Color child elements. The Color element has the following attributes.

Color Element

Attribute NameDescription
NameColor name.
R, G, B, AValues for the various color components in RGBA format. Each component is 8 bits, together forming a 32-bit color.

TagGroups Element

Declaration

<TagGroups>
	<TagGroup GroupName="MY_GROUP">
		<MultilingualName>
			<Japanese>My group</Japanese>
		</MultilingualName>
		<Tag
			TagName="MY_TAG"
			HasInside="False"
			CompareError="Strict">
			<MultilingualName>
				<Japanese>My tag</Japanese>
			</MultilingualName>
			<Comment>
				<Japanese>This is Comment</Japanese>
			</Comment>
			<Parameter
				Name="MY_PARAM"
				Type="String"
				Default="This is String Type parameter."
				LimitType="None">
				<MultilingualName>
					<Japanese>My parameter</Japanese>
				</MultilingualName>
				<ListItem
					Name="New_Item">
					<MultilingualName />
				</ListItem>
			</Parameter>
			<Default>
				<WidthCalcInfo
					Calculator="d545ff2d-63d0-43a4-b954-eba129dc7381">
					<Pixels>15</Pixels>
				</WidthCalcInfo>
			</Default>
		</Tag>
	</TagGroup>
</pre>

Description

The TagGroups element contains information about tag settings. The TagGroups element may contain zero or more TagGroup child elements.

The TagGroup element contains information about a single tag group. The TagGroup element has the following attributes and child elements.

TagGroup Element

Attribute NameDescription
GroupNameDefinition name of the tag group. The definition name must use only ASCII characters and be no more than 255 characters long.
ElementDescription
MultilingualName This element supports assigning names that correspond to multiple languages. The MultilingualName element contains the following child elements. These elements are omitted if their values are not set in MessageStudio, in which case MessageStudio displays the definition name instead.
ElementDescription
JapaneseName displayed when the application's language is set to "日本語" (Japanese). Can be set to any string value.
US_EnglishName displayed when the application's language is set to "US_English." Can be set to any string value.
TagStores the information for a single tag contained in this tag group. Multiple Tag elements can be present.

Tag Element

The Tag element contains information about tags. The Tag element has the following attributes and child elements.

Attribute NameDescription
TagNameDefinition name of the tag. The definition name must use only ASCII characters and be no more than 255 characters long.
HasInsideCan be set to "True" or "False." If "True," the tag is handled as a ranged tag. Ranged tags are tags that can themselves contain text.
CompareError Indicates the comparison conditions when the user runs a tag comparison. This must be one of the following values.
Strict
Replicates the behavior of the "Warning" setting and goes farther by generating warnings when tag parameters are not identical.
Warning
Warns if the number of tags within a message do not match.
Ignore
Generates no warnings for this tag.
ElementDescription
MultilingualNameThis element supports assigning names that correspond to multiple languages. It has the same structure as the TagGroup element's Multilingual element.
CommentComment for this tag. Supports multiple languages and has the same structure as the MultilingualName element.
ParameterStores the information for a single tag parameter contained in this tag. Multiple Parameter elements can be present.
Default Stores information about the default tag width settings. Unless this tag's width settings are customized per language in Substitute elements, these default values are used for the tag width. Tag width calculation methods can be extended by plug-ins, so information is embedded here to indicate which plug-in will be used.
Attribute NameDescription
CalculatorContains a GUID specifying which plug-in to use for calculating tag width.
The contents of this XML element differ depending on plug-in specifications.
Substitute Stores this tag's width information customized by language. Substitute elements contain the following elements in addition to those of the Default element.
Attribute NameDescription
LanguageName of the language this is customized for.

Parameter Element

The Parameter element contains information about tag parameters. The Parameter element has the following attributes and child elements.

Attribute NameDescription
NameDefinition name of the tag parameter. The definition name must use only ASCII characters and be no more than 255 characters long.
Type Parameter type. This must be one of the following values.
UInt8
Unsigned 8-bit integer.
UInt16
Unsigned 16-bit integer.
UInt32
Unsigned 32-bit integer.
Int8
Signed 8-bit integer.
Int16
Signed 16-bit integer.
Int32
Signed 32-bit integer.
Float
32-bit single-precision floating-point number.
Double
64-bit double-precision floating-point number.
String
String.
List
List. If set to this type, ListItem elements contain meaningful information.
DefaultDefault value for this parameter. When inserting a tag into text, this default value is used if this parameter is not otherwise explicitly specified. This value is treated as a fixed value if the LimitType attribute is set to "Fixed."
LimitEnabledThis attribute is not currently used. This is kept for backwards compatibility. Use the LimitType attribute instead.
LimitType Indicates what limits apply to values that can be entered for this parameter. This must be one of the following values.
None
No limits are placed on the value. If the Type attribute specifies a numeric type, the value is only constrained by the upper and lower value bounds of that data type.
UserLimit
Sets minimum and maximum value limits. The minimum is specified by the UserMinValue element, and the maximum by the UserMaxValue element.
Fixed
Specifies that this parameter's value is fixed. The value set in the Default attribute is used as the fixed value.
ElementDescription
UserMaxValueThe maximum value for this parameter. Used when the LimitType attribute is set to "UserLimit."
UserMinValueThe minimum value for this parameter. Used when the LimitType attribute is set to "UserLimit."
MultilingualNameThis element supports assigning names that correspond to multiple languages. It has the same structure as the TagGroup element's Multilingual element.
ListItem List items set for this parameter. Used when the Type attribute is set to "List." This element may be used more than once within the same parent element.
Attribute NameDescription
NameDefinition name of the item. The definition name must use only ASCII characters and be no more than 255 characters long.
ElementDescription
MultilingualNameThis element supports assigning names that correspond to multiple languages. It has the same structure as the TagGroup element's Multilingual element.

Attributes Element

Declaration

<Attributes>
	<Attribute
		Name="MY_ATTRIBUTE"
		Type="UInt8"
		Default="5"
		LimitEnabled="True">
		<UserMaxValue>10</UserMaxValue>
		<UserMinValue>0</UserMinValue>
		<MultilingualName>
			<Japanese>My Attr</Japanese>
		</MultilingualName>
		<MultilingualComment>
			<Japanese>This is Comment.</Japanese>
		</MultilingualComment>
		<Item
			Name="New_Item">
			<MultilingualName />
		</Item>
	</Attribute>
</Attributes>

Description

The Attributes element contains information about attribute settings. The Attributes element contains zero or more Attribute child elements.

Attribute Element

The Attribute element contains information about a single attribute. The Attribute element has the following attributes and child elements.

Attribute NameDescription
NameDefinition name of this attribute. The definition name must use only ASCII characters and be no more than 255 characters long.
Type Attribute type. This must be one of the following values.
UInt8
Unsigned 8-bit integer.
UInt16
Unsigned 16-bit integer.
UInt32
Unsigned 32-bit integer.
Int8
Signed 8-bit integer.
Int16
Signed 16-bit integer.
Int32
Signed 32-bit integer.
Float
32-bit single-precision floating-point number.
Double
64-bit double-precision floating-point number.
String
String.
List
List. If set to this type, Item elements contain meaningful information.
CommentThis attribute is not currently used. This is kept for backwards compatibility. Use the MultilingualComment element instead.
DefaultDefault value for this attribute. This default value is used if the parameter is not otherwise explicitly specified.
LimitEnabledIndicates whether to set limits on values that can be entered for this attribute. Can be set to "True" or "False." If "True," the minimum is specified by the UserMinValue element, and the maximum by the UserMaxValue element.
ElementDescription
UserMaxValueThe maximum value for this parameter. Used when the LimitEnabled attribute is set to "True."
UserMinValueThe minimum value for this parameter. Used when the LimitEnabled attribute is set to "True."
MultilingualNameThis element supports assigning names that correspond to multiple languages. It has the same structure as the TagGroup element's Multilingual element.
MultilingualCommentComment for this attribute. Supports multiple languages and has the same structure as the MultilingualName element.
Item List items set for this attribute. Used when the Type attribute is set to "List." This element may be used more than once within the same parent element.
Attribute NameDescription
NameDefinition name of the item. The definition name must use only ASCII characters and be no more than 255 characters long.
DisplayNameThis attribute is not currently used. This is kept for backwards compatibility. Use the MultilingualName element instead.
ElementDescription
MultilingualNameThis element supports assigning names that correspond to multiple languages. It has the same structure as the TagGroup element's Multilingual element.

Dictionaries Element

Declaration

<Dictionaries>
	<Dictionary Name="en_US">
		<ExtraWord>mstxt</ExtraWord>
		<ExtraWord>gmm</ExtraWord>
		...
	</Dictionary>
	...
</Dictionaries>

Description

The Dictionaries element contains information about additional words to add to a dictionary. See How to Use Spell Check for details on dictionaries and adding words to them. The Dictionaries element contains zero or more Dictionary child elements.

Dictionary Element

Attribute NameDescription
NameName of the dictionary to add words to.
ElementDescription
ExtraWordA single word to add to the dictionary. This element may be used more than once within the same parent element.

BuilderSettings Element

Declaration

<BuildSettings>
	<BuildSetting
		Builder="45e0d427-0349-45b3-8015-c5e4cc773460">
		<AttributeHeader
			HeaderPath="$(ProjectDir)\include\ms_attributes.h"
			Encoding="932"
			ItemPrefix="MSATTRITEM_" />
	</BuildSetting>
	<BuildSetting
		Builder="8857dfd8-959a-4029-afcc-7db874bd58e8">
		<MessageBinInfo
			OutputDir="$(ProjectDir)\bin\$(LanguageName)\$(InputFileName).msbt"
			Encoding="UTF16"
			Newline="LF"
			IsLittleEndian="False"
			HasLabelBlock="True"
			HashSize="101"
			HasAttributeBlock="True"
			DirectColor="True" />
	</BuildSetting>
	...
</BuildSettings>

Description

The BuilderSettings element contains information about builder plug-in settings. The BuilderSettings element contains zero or more BuilderSetting child elements.

BuilderSetting Element

The BuilderSetting element contains settings information for a single builder plug-in. The BuilderSetting element has the following attributes.

Attribute NameDescription
BuilderGUID indicating a builder plug-in.

As shown by the AttributeHeader and MessageBinInfo elements in the Declaration example above, this element can also contain user-defined elements. These elements can be added by the builder plug-in specified in the Builder attribute. MessageStudio itself does not directly process these elements.

Roles Element

Declaration

<Roles>
	<Administrator
		Password="kmPKnUp79QbJSj1k/WjaE3tIXKPmSp0j2Xoh0IEk5sk=" />
	<RestrictedRole Name="JP_Japanese editor">
		<Forbidden Permission="234a7423-2b39-47ed-a343-8207b935fe06">
			<Subkey Name="US_English" />
		</Forbidden>
		<Forbidden Permission="4040d647-c07f-4e9b-9334-95b62ef0e00a" />
		<Forbidden Permission="40bc80ae-4158-413a-8a89-0620daecd70e" />
		...
	</RestrictedRole>
	...
</Roles>

The Roles element contains information about roles and permissions. The Roles element has the following attributes and child elements.

ElementDescription
Administrator Contains information about the administrator role. The administrator has the rights to perform all operations. This element has the following attributes.
Attribute NameDescription
PasswordThe password required to log in as an administrator. This value is encoded using the SHA256 and BASE64 algorithms.
RestrictedRole Indicates a single role. Multiple RestrictedRole elements can be present. Roles have certain permissions set, and those permissions are each indicated by a Forbidden element. The Forbidden element has the following attributes and child elements.

Forbidden Element

Attribute NameDescription
PermissionGUID indicating the permissions plug-in used.
ElementDescription
SubkeyHolds a Name attribute, whose value is defined by the permissions plug-in.

ExtraSettings Element

Declaration

<ExtraSettings>
	<ExtData DataHolder="4520d7e7-1449-498b-bd1d-784ee068c2d7" />
	<ExtData DataHolder="d5290830-ab71-4923-a9b3-ad88cfaf7f2c">
		<SaveBuild_ButtonName xmlns="nintendo:msgstudio">
			Commit
		</SaveBuild_ButtonName>
		<SaveBuild_CommitMessage xmlns="nintendo:msgstudio">
			commit by @(USERNAME)
		</SaveBuild_CommitMessage>
		<SaveBuild_PostProcess xmlns="nintendo:msgstudio" />
		<Execute_ButtonName xmlns="nintendo:msgstudio">
			Run
		</Execute_ButtonName>
		<Execute_Process xmlns="nintendo:msgstudio" />
	</ExtData>
	...
</ExtraSettings>

Description

The ExtraSettings element contains information about settings for the various types of plug-ins. The ExtraSettings element contains zero or more ExtraData child elements.

ExtraData Element

The ExtraData element has the following attributes.

Attribute NameDescription
DataHolderGUID to identify the plug-in.

As shown by the SaveBuild and Execute elements in the Declaration example above, the ExtraData element can also contain user-defined elements. These elements can be added by the plug-in specified in the DataHolder attribute. MessageStudio itself does not directly process these elements.
