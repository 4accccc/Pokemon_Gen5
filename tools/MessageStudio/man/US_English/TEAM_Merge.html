Conflicts and Merging

What is a conflict?

A conflict occurs when a section of text that you have edited is also edited by someone else. Even if the same file has been edited, as long as the location of the edits is different, Message Studio will automatically Merge these changes (compile them), but when the same text has been edited, it becomes necessary to Merge manually.

If a conflict occurs, a warning mark will appear on Content File in the Project Explorer. Files like these must be merged manually.

With regard to Message Files (*.mstxt), if the same cell is edited at the same time in multiple places, a conflict will occur. If the same file is edited in multiple places but all the cells are different then a conflict will not occur.

Merge

Overview

Merging is when one file is edited in mutiple places and those changes are compiled without problem.

There is a difference between the Message Studio meaning of merging and the MMS meaning.
For more on how they differ, please see For MMS Users.

Auto-Merge

Even when one file has been edited in multiple locations at the same time, as long as where the changes were made differs (different cells in the Message Filem Message Studio will auto-merge these revisions. This auto-merge will happen when the file is "Updated". Only when the same cells are edited will a conflict occur on that file and a manual merge like the one below become necessary.

Manual Merge

In a file where a confloct has occured, a warning mark like the image below will appear on the file in the Project Explorer.

Double clicking on the file will cause a window to appear and a merge will begin. There are 3 ways to manually merge a file so please select the one most appropriate to what's happening at the time.



MethodExplanation
Editing a ConflictEach of the conflicts in this file will be merged individually. Because they will be merged individually, this is the safest way to merge. For details on how this happens, please see "Editing Conflicts".
Using the Server FilesThis will allow you to discard the file you have be editing and use the file on the server. If you use this method, any revisions that you made since pulling the data from the server will be lost so please be careful.
Using Your Own FileThis will discard the file on the server and replace it with the file that you have edited. If you use this method, once you have pulled the data off the server, any changes made by others from that point on will be as though they never happened so be careful. We do not necessarily recommend this method of resolving a conflict.
CancelThis will put the merge process on hold. However, it is recommended that conflicts be resolved as soon as possible.

Merge Tool

Overview

In order to resolve the conflict in each cell, you will use the manual merge tools shown below. Here we will explain how to use the manual merge tools.

Merging Cells

As in the image, cells with conflicts will be shown in pink.

If you double click on the cell with the conflict, the window below will open and allow you to merge. If you press the "Use My Text" button on the left, the text you created will fill that cell and all other edited versions will be deleted. If you press the "Use the text on the server" button on the right, then the text created somewhere else will be used and your edited version will be deleted.

Cells that have been merged will change color depending on how the text was merged. The chart below explains this.

ConditionMeaningExplanation
Not mergedCells that have not yet been merged.
Use my textThe text that you created will be used and other edits will be deleted.
Use the text on the serverThe text that was created elsewhere will be used and your text will be deleted.

When all conflicts have been resolved, press the "Resolve Conflicts" button in the upper left. If there are still some remaining conflicts, you will be urged to continue merging.

Button Explanation

With the merge tools, so that the merge process goes as smoothly as possible, there are several buttons to perform these actions. Here is an explanation of each of the buttons.
ButtonsMeaningExplanation
Conflicts ResolvedOnce the conflicts in this file have been resolved, the merging process will end. Press this once all the cells have completed merging. If this button is pressed with unresolved cells, you will be urged to continue to merge.
UndoRevert to Previous Merge
Do over"Undo" Depending on when this is used, a reverted merge can be restored.
Previous Conflict LocationYou will jump to the previous conflict location.
Next Conflict LocationYou will jump to the next conflict location.
