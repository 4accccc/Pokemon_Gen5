LMS_GetContentsNum

This function gets the number of content files that have been output to the project binary CTI1 block.

Syntax

libms_s32_t LMS_GetContentsNum( LMSProjFile* pFile );

Arguments

Argument NameTypeDescription
pFileLMSProjFile*Specify the project file object whose number of content files you want to get. (This project file object is the return value from the LMS_InitProject function.)

Return Value

On success, returns the number of content files. On failure, returns eLMSRet_NotFound.
