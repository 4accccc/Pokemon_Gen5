Plugin Types

This page will explain what kind of things are made possible by creating and using a plugin. Below is a list of the features that are possible through the use of a plugin.

Add Menu Plugin

Using a Add Menu Plugi, menus can be added to the Message Studio Menu Bar. Also, this menu can also be added to the Project Explorer, etc.

By preparing a plugin with features like these, the user can add standardized actions as one menu item. For example, when a character appears on the map and their speech text needs to say something different depending on the conditions -- if the user needs to separate these two conversations in the file, it's a painstaking process to have to do this for each character that is added. If actions like this were to be standardized as a menu item, the user could make it so that files are automatically added based on a naming rule.

Add Tool Strip

A Tool Strip Bar can be added to the Message Studio. A button for the Tool Strip Bar can be added like a normal tool bar. In addition, it is also possible to added combo boxes, labels, etc., and other UI features. These can be used for standardized commands like the Add Menu.

Builder Plugin

By using a Builder Plugin, you can add a build process into the program which will be activated when the Build menu is selected. If this plugin added to the settings, files that are output regularly can be added. For example, this can be used when the memory is severely limited but you want to output an optimized resource file. Also, when you want to include original additional information in the resource file, the program supports the inclusion of setting documentation that would exist independent of the game data.

Please also see About Resource Files.

Command Line Plugin

By adding a Command Line Plugin to the project, an original Command Line Switch can be defined. For example, by using this information can be imported periodically from the outside and deleted as well. Also, this can be used when you want the Message Studio to perform a separate function in prior to an executable file creation command like one that would use "Make file".

This construction can be used in a variety of ways. As just one example, if a spell check is run external to the application and an error occurs, the ROM prodiuction can be stopped temporarily. Also, data from an external file (for example, the Layout Editor that exists as a part of the Nintendo Ware for Revolution) can be included as a part of a Message Studio project file.

Content Plugin

Use of this Content Plugin makes it possible to increase they type of files that can be used with the Message Studio. In addition to message files (mstxt), the Message Studio is capable of handling and managing a variety of different types of files. For example, a flow chart file can be used. Also, as long as they are applied, files that use external script languages can also be used.

Exporter Plugin

By using an Exporter Plugin, a file can be output as a separate external format. It might not sound any different from a Builder Plugin but while a Builder Plugin is used to set files that are output on a daily basis, the Exporter Plugin will only perform this action when it is selected from the menu, so it has the ability to create reports and the flexibility to convert to specified formats. For example, if there is an Exporter Plugin that exports to Adobe Reader or Excel, etc., then it will no longer be necessary to send this data out of house (for example as a script for a voice recording or to the rating board, etc.) as a Message Studio file.

Expension Project Option Plugin

If you use this plugin. you will be able to export or import additional data to the Project User Setting file (mpuo). This plugin is usually not used alone but it is used in conjunction and cooperation with other plugins.

Expansion Project Parameter Plugin

This is the same as the above except that this does not import additional information to project user options (mpuo files) but to project files (msproj).

Font Loader Plugin

Using the Font Loader Plugin, you can increase the types of fonts that you can use with the Message Studio. With teams that use independent 2D rendering systems, the font data can be exported using a proprietary Font Loader and imported to the Message Studio. Nintendo Ware for Revolution and TWL System format Font Loaders come standard with the Message Studio.

Importer Plugin

This is the opposite of the Exporter Plugin in that this feature takes an external file and converts is to a content file to implement it into the project. For example, it may be beneficial to use this when sharing assets like an Excel, CSV, or a file created using another tool.

Permission Plugin

You can open new permission information in the Project File (msproj). This permission information is usually created with other plugin features and used together. For example, a menu might have been created using the Add Menu Plugin but if you don't want anyone but the program manager to press it, by creating a Permission Plugin at the same time, you can limit permissions as well.

Rendering Method Plugin

Using a Rendering Method Plugin, an emulation 2D rending system distinct to the game can be performed. The Message Studio includes Nintendo Ware for Revolution and TWL System emulation systems that will be utilized when the default settings are employed.

The rendering method has been created to work in conjunction with the style feature. Details are summaried here.

Additional Message Columns

This Plugin will allow for a distinct column to be added to the message grid. By using this Plugin, you can do things like provide users with buttons that perform certain functions or have data including text data to display in a different way.

Empty Plugin

You can also create a plugin that will cause nothing to happen from the system side. It's main use would be for "observation". If the Message Studio is set up so that an action occurs when the system is re-formatted, you can set it to perform specific actions.
