Plug-In Creation Tutorial

Plug-In Creation Overview

MessageStudio plug-ins are created as .NET framework class libraries (*.dll files). To work with them, you need to be familiar with a programming language that can create a .NET assembly. Specific examples include Visual Basic.NET, C#, or IronPython.

In this chapter, we introduce how to create a MessageStudio plug-in using Microsoft Visual Studio and C#. You can use other software besides Visual Studio to create plug-ins, but we will not describe those methods here. To create a plug-in, you need Visual Studio version 2005 or later. You can also use the free Express Edition to build plug-ins.

Note: The images and steps described are for Visual Studio 2008 Standard Edition. Depending on your edition and version of Visual Studio, some of the menu items mentioned here might not exist for you.

Create a Project

First, launch Microsoft Visual Studio and create a project. From the Visual C# menu, select Class Library. Make sure that .NET Framework 2.0 is selected in the drop-down menu. (In Visual Studio 2005, this is always selected.) Enter the name of the plug-in in the Name field.

After creating a new project, copy the bin directory from the MessageStudio package over to the newly created project directory. Give the copied directory an informative name, such as MessageStudioBin.

Next, add reference settings. Adding references allows you to use the classes and interfaces in the .NET assembly that have been declared as public. In Visual Studio's Solution Explorer, right-click References and select Add Reference.

Click the Browse tab, then select the MessageStudio.exe file that you copied earlier and click OK. Also add a reference to System.Windows.Forms.dll. This is a .NET standard library, so instead of clicking the Browse tab, choose it from among the .NET components.

Your plug-in project is now set up and ready for development.

Creating a Simple Plug-In

Now we can start coding. In this basic example, we will add a menu to the MessageStudio program.

The first step is to rename the automatically generated Class1 class to MyMenu. This class will be accessed from external assemblies, so declare it as public. Now let's make the MyMenu class implement the IAdditionalMenuItemPlugin interface. This interface is included in MessageStudio.exe. Use the menus displayed in Visual Studio to add a namespace for use in the source code (the default keyboard shortcut is SHIFT+ALT+F10). Add declarations for all methods that the interface must implement. (You can also do this by selecting the interface name with the cursor and pressing SHIFT+ALT+F10.) The steps so far should produce a MyMenu.cs file as follows. 

using System;
using System.Collections.Generic;
using System.Text;
using Nintendo.MessageStudio.Core.Plugin;

namespace MyPlugin
{
	public class MyMenu : IAdditionalMenuItemPlugin
	{
		public System.Windows.Forms.ToolStripMenuItem CreateMenuItem()
		{
			throw new NotImplementedException();
		}

		public AdditionalMenuType MenuType
		{
			get { throw new NotImplementedException(); }
		}

		public void SetupPlugin( PluginInitArgs args )
		{
			throw new NotImplementedException();
		}

		public void TearDownPlugin()
		{
			throw new NotImplementedException();
		}
	}
}

First implement the SetupPlugin and TearDownPlugin methods. At this point, you do not need to do anything with these methods. These methods implement the processing used when the plug-in is initialized and when it is terminated. Delete the locations in the code which throw NotImplementedException.

The CreateMenuItem method creates and returns menu items to register in MessageStudio. Add code to register an event when the menu item is clicked and display the message, Hello, MessageStudio! All of this so far should match the following code. 

public void SetupPlugin( PluginInitArgs args )
{
}

public void TearDownPlugin()
{
}

public ToolStripMenuItem CreateMenuItem()
{
	ToolStripMenuItem menu = new ToolStripMenuItem();
	menu.Name = "MyMenuItem";
	menu.Text = "My First Plug-in menu";
	menu.Click += new EventHandler( menu_Click );
	return menu;
}

private void menu_Click( object sender, EventArgs e )
{
	MessageBox.Show( "Hello, Message Studio!" );
}

Next, implement the property that specifies where to add this new menu. To add the new menu as an item on the bottom of the MessageStudio Project menu, add the following code. 

public AdditionalMenuType MenuType
{
	get { return AdditionalMenuType.ProjectMenu; }
}

The plug-in is now implemented. Now use Build to create the plug-in DLL file. Use the resulting MyPlugin.dll file as a plug-in. (See the Plug-ins Overview Plug-ins Overview page for how to use plug-ins.)

Make sure the MyPlugin.dll file is copied to the plug-in path specified in the project file (*.msproj). Open MessageStudio and the plug-in will be used, resulting in an additional menu item.

The event handler is called when the menu item is clicked.

This completes the example of how to create a plug-in. See the Types of Plug-ins page to learn about what kinds of plug-ins can be created. Also see the DeveloperGuide.chm file in the package's doc directory for a reference manual on plug-in implementation. (Note: This document is not provided in English.)
