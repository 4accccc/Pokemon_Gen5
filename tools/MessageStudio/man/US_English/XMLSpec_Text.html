MessageStudioText Element (Root Element)

Declaration

<?xml version="1.0" encoding="utf-8" standalone="yes"?>
<MessageStudioText Format="1.2" xmlns="nintendo:msgstudio">
	...
</MessageStudioText>

Description

The MessageStudioText element is the root element for message text files. This element has the following attributes. It also has the TextRow child element.

Attribute NameDescription
xmlnsXML namespace. This value is always nintendo:msgstudio.
FormatMessage text file format version. This version is for the message text file format itself, and may differ from the MessageStudio software version. The current version is 1.1.

TextRow Element

Declaration

<TextRow Label="MyText"
	Style="MyStyle"
	Category="381EEEB1-2B01-4b48-AB47-A32FB9B172E0">
	...
</TextRow>

Description

The TextRow element holds the data for one line (one text string) in the MessageStudio message grid. This element has the following attributes and child elements.

Attribute NameDescription
LabelA short name for easy identification of the line of text.
Category The text type. This attribute can be extended by using external plug-ins. The XML Category attribute holds a GUID to identify the plug-in to use. The GUID values for the basic features provided by MessageStudio are shown below.
BD926301-75EE-44ce-B96E-8F26EE289788
Standard text GUID. The XML Category attribute can be omitted only for standard text.
381EEEB1-2B01-4b48-AB47-A32FB9B172E0
Unused text.
AE0E0905-E6CF-44be-8AB1-508E5F158DEF
Text embedded into textures.
68A54FCA-5809-4bdf-970D-8976D35CB10B
Text embedded directly into the program and not used as an external resource. Used for errors or other messages displayed in cases such as when a resource cannot be loaded from the DVD.
StyleThe style applied to the text. This value is meant to be set to a StyleClass style configured in the project file, but there is no guarantee that such styles exist.

The following elements appear in this order.

ElementDescription
LanguageCellSee the LanguageCell element.
CommentCellSee the CommentCell element.
AttributeCellSee the AttributeCell element.
ExtraCellSee the ExtraCell element.

LanguageCell Element

Declaration

<LanguageCell Language="US_English">
	<Text>Hello, Message Studio.</Text>
	<TextModifiedBy
		User="userA:USERA-PC"
		Time="2009-09-01T01:48:52" />
	<Status>Editing</Status>
	<StatusModifiedBy
		User="userA:USERA-PC"
		Time="2009-09-10T01:48:51" />
	<Review>ReviewConfirmed</Review>
	<ReviewModifiedBy
		User="userB:USERB-PC"
		Time="2009-09-12T02:43:11" />
	<CompletedAt>2009-09-10T01:48:51</CompletedAt>
	<ReviewedAt>2009-09-12T02:43:11</ReviewedAt>
	<TextHistory>
		<OldText>Hello, this is Message Studio.</OldText>
		<OldTextModifiedBy
			User="userA:USERA-PC"
			Time="2009-08-31T01:48:52" />
	</TextHistory>
	<TextHistory>
		<OldText>test test test</OldText>
		<OldTextModifiedBy
			User="userA:USERA-PC"
			Time="2009-08-30T01:48:52" />
	</TextHistory>
</LanguageCell>

Description

The actual text of a TextRow element is held in LanguageCell elements, one per each language. This element has the following attributes and child elements.

Attribute NameDescription
LanguageThis attribute holds the language name. This is meant to be a language name that is defined in the project settings, but there is no guarantee that any such settings exist.

The following elements appear in this order.

ElementDescription
TextThe actual text (message). See Details for specifics.
TextModifiedBy Shows who last modified the contents of the Text element. This has the following attributes.
Attribute NameDescription
UserName of the person who modified the text. Entered in the format "username:computername".
TimeDate of modification. Entered in the ISO8601 UTC (Universal Time, Coordinated) format.
Status Translation status. This must be one of the following values.
NotYet
Not yet processed. Not yet edited either. This value can be used, but in general, in situations where it would be used, the text does not possess a LanguageCell element anyway. Consequently, there are no real guidelines for using the NotYet value.
Editing
Currently being edited.
Completed
Editing is complete.
StatusModifiedBy Shows who last modified the contents of the Status element. Has the same attributes as the TextModifiedBy element.
Review Review status. This element is not present if review features are not enabled or if no review has ever been requested.
NotYet
No review has yet been requested. This value can be used, but in general, in situations where it would be used, the text does not possess a Review element anyway. Consequently, there are no real guidelines for using the NotYet value.
ReviewRequested
Review has been requested and the text is under review.
ReviewRejected
Upon review, the text was rejected.
ReviewConfirmed
Upon review, the text was accepted.
ReviewModifiedBy Shows who last modified the contents of the Review element. If a Review element is present, it always includes this element. Has the same attributes as the TextModifiedBy element.
CompletedAtThe date at which the Status element value was set to Completed. If the Status element has never been set to Completed, this element is omitted. After the Status element has been set to Completed at least once, MessageStudio uses this element to be aware of the situation if the Status element is then reverted back to Editing.
ReviewedAtThe date at which the Review element value was set to ReviewConfirmed. If the Review element has never been set to ReviewConfirmed, this element is omitted. After the Review element has been set to ReviewConfirmed at least once, MessageStudio uses this element to be aware of the situation if the Review element is then reverted back to ReviewRequested.
TextHistoryこの要素はフォーマットVer1.2以降で利用可能です。 ユーザーが「再編集」を行うたびに自動的に作成される要素で、 これを参照することで、翻訳者は何が変わったのかを サーバに問い合わせることなくスムーズに表示することが出来ます。 この要素はLanguageCell要素の中に複数個出現させることが出来ます。 まだ再編集が行われていない場合、この要素は出現しません。

Details

The Text element contents are entered in the same format as MessageStudio source strings. MessageStudio parses and loads text in this format. See the description of Source Strings for syntax details.

Cell Status in MessageStudio

LanguageCell elements only save the status of their own cell. However, there are other statuses in MessageStudio beyond the values recorded in the Status element, such as "Translation Requested."
When an .mstxt file is opened in MessageStudio, the status of cells is determined by checking the parent-child relationships in accordance with the language tree. See Language Cell Status for specifics.
The following table shows examples of possible child cell statuses of two language cells in a parent-child relationship.

Parent StatusChild StatusTime StampChild Status in the Grid
CompletedNotYetTranslation Required
CompletedEditingTranslation Required
CompletedCompletedParent < Child Completed
EditingCompletedParent Editing
CompletedCompletedChild <= ParentTranslation Required Again

Note

Note that a LanguageCell element is not necessarily present for every language defined in the project file. Empty cells (a blank white background) in the message grid, where the Status element would be set to "NotYet," indicate places where there is no LanguageCell element for that language.

No LanguageCell element may be included for any language not defined in the project. If a project file includes such a LanguageCell element, MessageStudio ignores it.

To minimize the occurrence of conflicts in projects under team management, MessageStudio sorts LanguageCell elements by language (their Language attribute value) and stores them in that order.

CommentCell Element

Declaration

<CommentCell Language="US_English">
	<Comment>This is test comment.</Comment>
	<CommentModifiedBy
		User="user:USER-PC"
		Time="2009-09-11T05:13:27" />
</CommentCell>

Description

Comments about individual TextRow elements are held in CommentCell elements, one per each language. This element has the following attributes and child elements.

Attribute NameDescription
LanguageThis attribute holds the language name. This is meant to be a language name that is defined in the project settings, but there is no guarantee that any such settings exist.

The following elements appear in this order.

ElementDescription
CommentThe comment.
CommentModifiedBy Shows who last modified the Comment element. Has the same attributes as the TextModifiedBy element.

Note

As with LanguageCell elements, note that a CommentCell element is not necessarily present for every language defined in the project file. The CommentCell element is omitted for languages whose comment cell is empty.

No CommentCell element may be included for any language not defined in the project. If a project file includes such a CommentCell element, MessageStudio ignores it.

To minimize the occurrence of conflicts in projects under team management, MessageStudio sorts CommentCell elements by language (their Language attribute value) and stores them in that order.

AttributeCell Element

Declaration

<AttributeCell Name="MyAttribute">
	<Text>This is String Type attribute.</Text>
	<TextModifiedBy
		User="user:USER-PC"
		Time="2009-09-11T05:13:27" />
</AttributeCell>

Description

Comments about individual TextRow elements are held in CommentCell elements, one per each language. This element has the following attributes and child elements.

Attribute NameDescription
NameAttribute name.

The following elements appear in this order.

ElementDescription
TextCurrently-set value.
TextModifiedBy Shows who last modified the attribute value. Has the same attributes as the TextModifiedBy element.

Note

Note that an AttributeCell element is not necessarily present for every attribute defined in the project file. AttributeCell elements are omitted for any attributes set to their default values.

ExtraCell Element

Declaration

<ExtraCell DataHolder="EABC1FB1-D8A2-4869-BB83-8C0ABD1CA33D">
	<CellData>data</CellData>
	<CellModifiedBy
		User="user:USER-PC"
		Time="2009-09-11T05:13:27" />
</ExtraCell>

Description

ExtraCell elements are optional elements that are added with the Additional Message Column Plug-in and contain user-defined data. This element has the following attributes and child elements.

Attribute NameDescription
DataHolderGUID to identify the Additional Message Column Plug-in. All plug-ins are identified by uniquely assigned GUIDs.

The following elements appear in this order.

ElementDescription
CellDataCurrently-set value. Saves user-defined data as a string.
CellModifiedBy Shows who last modified this cell. Has the same attributes as the TextModifiedBy element.
