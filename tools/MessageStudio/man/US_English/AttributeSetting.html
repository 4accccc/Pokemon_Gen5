About Attribute Settings

What Are Attributes?

A message file (*.mstxt) is a content file that contains many lines of text. You can assign different settings to each line of text for when it's output to the game. These settings are called attributes.

Although you can modify attribute settings, how this information is used depends on the structure of the game. For this reason, the development team must determine on their end how this attribute information will be used. Here are some example attributes:

  • Text Format (centered or left justified)
  • The camera used when a message is displayed.
  • The degree to which the relationship between the player and NPC (non-player character) changes when a message is displayed.
  • The kind of sound effects used when the message appears.
  • Conditions under which the message is displayed? (What time, etc.)
  • The item that's given when this message is displayed.

The kind of attributes created can be affected by aspects like the game or hardware specs (amount of memory, etc.). Please work closely with the programmer to determine what kind of settings are necessary. Of course, it's also possible to not use attributes at all or to add them later.

Setting Attributes

To set attributes, start by selecting "Add or Delete Attributes" from the "Project" menu.

The Add or Delete Attributes dialog box will appear. The left side of this box will show a list of the currently registered attributes. If you used the Project Wizard to create your project, no attributes will be registered.

Add and delete attributes using the main toolbar at the top. If you choose an attribute on the left, its details appear in the right panel.

About Attribute Styles

Each attribute has its own style settings. These settings determine what kind of information each attribute has. They can largely be broken into three categories: values, character strings, and lists. For numeric attributes, there are multiple variations. As for which of these will be used, this is largely a decision best left to the programmer.

If an attribute is set as a numeric type, a value within the set range will be assigned to the text. This is used for a variety of applications--for example, if after a message is displayed, the amount of money lost or gained needs to appear. If a numeric attribute is added, a number entry control will appear in that cell.

Using a character string type allows character string data to be added as an attribute. Characters entered can be output to the game, but attribute characters are not the best for translating, so this use is limited. This has been created with the idea that it would be used as an identifier. (For example, as the name of the already read flag.)

Create a list form to create an attribute where one item is selected from a list. For example, if you wanted to set the attribute so that a particular sound effect plays when a message is displayed, setting the attribute as a numerical value could be very cumbersome to the user. The team would have to manage which sound effect is ID0 as opposed to ID1, and it's difficult to know which is which when all you have is an ID number to work with. However, with a list form, it will only be possible to choose one item from a list, though ultimately it will be output as a number (in other words, the ID. Names can also be given to entries, also improving comprehensibility.

定義名と表示名

Message Studioでは、属性を定義名によって識別します。 定義名には、ASCIIによって定義される文字のみを利用することが出来ます。 それとは別に、編集がやりやすいように別の名前をつけることが出来ます。 これを「表示名」と呼びます。 この表示名には、Message Studioのユーザーインターフェイスの 言語設定に応じて複数の名称をつけることが出来ます。

デフォルト値について

属性には、デフォルト値を設定します。 デフォルト値とは、ユーザーが明示的に入力しなかった場合に属性セルに適用される値のことです。 最もよく利用されるような値(例えば、「ゲーム内通貨の増減」であれば0、「アイテムの追加」であれば「なし」など)を デフォルト値として登録されておくことを推奨します。

属性で、ユーザーが明示的に設定したセルは、ボールド体のフォントで強調表示されます。 セルでDeleteキーを押下すると、ユーザーが明示的に設定した値は削除され、デフォルト値に戻ります。

属性セルのボールド体表示機能を無効化するには、 「表示」メニューから「グリッドの表示設定」を選択します。

Cautions for Setting Attributes (For the Programmer)

About Double Precision Floating Point Form (double)

Double precision floating point form (double form) can handle attributes for 64-bit data volumes. However, depending on the game's processor, it might not be compatible with the double form processor. Particularly in the case of the Nintendo DS, calculation time can increase, so please be careful when creating the settings.

About Alignment Adjustment

With Message Studio, all attributes entered will be output in order from the top. The structure of attributes will be lined up without gaps so the order assigned can dramatically affect performance. For example, take the below attribute order for a 32-bit processor:

  • s8 (coded 8-bit integer) Attribute
  • s32 (coded 32-bit integer) Attribute

If they are set up like this, because the second attrbute is positioned so that it exceeds the boundary, it might become necessary to include an extra command to ensure that it's accessed. In order to avoid problems like this, though it might be a waste, the initial form should be aligned to the 32-bit boundary. By doing this, each value will be positioned correctly relative to the boundary. Also, Message Studio does not include a feature that pads attributes.

属性出力フィルタリング

プロジェクトに設定された属性情報は、 全てを全ての場面で利用するとは限りません。 例えば、「ゲーム内通貨増減」という属性があったとしても、 この属性はエラーメッセージでは利用されません。 全てのテキストに対して属性情報を出力すると、それだけメモリを余分に消費し、効率的ではありません。

そこで、特定のメッセージファイル(*.mstxt)において、 属性データを出力させない設定をメタ情報として行うことが出来ます。 まず、フィルタリングを有効にしたいファイルまたはフォルダを プロジェクトエクスプローラ上で右クリックし、「メタ情報の設定」を押下します。

「メタ情報の追加」から「属性フィルタリング」を選択し、 フィルタリングしたい属性の名前を入力してください。 なお、ここで入力する属性の名称は定義名であり、表示名を入力しても有効にはなりませんのでご注意ください。
