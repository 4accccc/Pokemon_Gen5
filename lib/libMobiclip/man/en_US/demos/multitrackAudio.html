Mobiclip multitrackAudio Sample Demo

Location

libMobiclip/build/demos/Mobiclip/multitrackAudio

Compile Method

From a Cygwin prompt go to the libMobiclip/build/demos/Mobiclip/multitrackAudio directory, and enter

% make

Compiling will begin, and the SRL executable file and the NEF or TEF files with binary information will be generated in libMobiclip/build/demos/Mobiclip/multitrackAudio/bin/platform/target.

For example:

libMobiclip/build/demos/Mobiclip/multitrackAudio/bin/ARM9-TS/Release/multitrackAudio.srl

will be the executable file for the multitrackAudio demo.

Execution

For NITRO ROMs

If using IS-NITRO-DEBUGGER:

  • Load and execute an NLF file with IS-NITRO-DEBUGGER
  • Execute an SRL file with IS-NITRO-DEBUGGER
  • Execute an SRL file with IS-NITRO-DEBUGGER using the loadrun.exe tool from a command line

If using IS-TWL-DEBUGGER:

  • Load and execute an NLF file with IS-TWL-DEBUGGER.
  • Execute an SRL file with IS-TWL-DEBUGGER
  • Execute an SRL file with IS-TWL-DEBUGGER using the loadrun.TWL.exe tool from a command line

For TWL/NITRO HYBRID ROMs

If using IS-NITRO-DEBUGGER:

  • Execute an SRL file with IS-NITRO-DEBUGGER
  • Execute an SRL file with IS-NITRO-DEBUGGER using the loadrun.exe tool from a command line

If using IS-TWL-DEBUGGER:

  • Load and execute a TLF file with IS-TWL-DEBUGGER
  • Execute an SRL file with IS-TWL-DEBUGGER
  • Execute an SRL file with IS-TWL-DEBUGGER using the loadrun.TWL.exe tool from a command line

For TWL LIMITED ROMs

If using IS-TWL-DEBUGGER:

  • Load and execute a TLF file with IS-TWL-DEBUGGER
  • Execute an SRL file with IS-TWL-DEBUGGER
  • Execute an SRL file with IS-TWL-DEBUGGER using the loadrun.TWL.exe tool from a command line

Description

Plays a Mobiclip movie containing several audio tracks.
Only one audio track is played at once and can be changed interactively.
You can pause/resume video playback by using START button.
You can stop video playback by using B button.
You can restart video playback by using A button.
You can select loop disable/enable by using SELECT button.
You can select next/previous audio track to play by using R and L button.
LCD power is off/on when DS cover is closed/opened.

Operating Environment

We have confirmed normal operation for all of the samples using either IS-NITRO-EMULATOR or IS-TWL-DEBUGGER.
