MO_GetVideoHeight

C Specification

#include <nitro/Mobiclip.h>

u32 MO_GetVideoHeight ( MOHandle handle );

Description

Get the height of the movie in pixels.

Arguments

handle Valid handle movie.

Return Values

The height of the movie or 0 if the handle is MO_INVALID_HANDLE.
