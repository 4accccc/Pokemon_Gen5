MO_CloseMovie

C Specification

#include <nitro/Mobiclip.h>

void MO_CloseMovie ( MOHandle handle );

Description

Close a Mobiclip movie.
MO_Free is called inside this function.

Arguments

handle Valid handle movie, if this is MO_INVALID_HANDLE the function does nothing.

Return Values

None.
