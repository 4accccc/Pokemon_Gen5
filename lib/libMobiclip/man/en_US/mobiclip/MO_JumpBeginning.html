MO_JumpBeginning

C Specification

#include <nitro/Mobiclip.h>

u32 MO_JumpBeginning ( MOHandle handle );

Description

Go to the beginning of the movie.

Arguments

handle Valid handle movie.

Return Values

1 if no error, 0 if error or if the handle is MO_INVALID_HANDLE.
