MO_JumpNextIframe

C Specification

#include <nitro/Mobiclip.h>

u32 MO_JumpNextIframe ( MOHandle handle );

Description

Go to the next movie I-frame (keyframe).
To be more specific if the current frame is a keyframe then it moves to the next keyframe, otherwise it skips the next keyframe and moves to the subsequent one.
Doing that allows us to iteratively move to the end of the movie only by calling this function in a loop.

Arguments

handle Valid handle movie.

Return Values

1 if no error, 0 if error or if the handle is MO_INVALID_HANDLE.
