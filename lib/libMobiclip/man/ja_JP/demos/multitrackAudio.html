Mobiclip multitrackAudio サンプルデモ

場所

libMobiclip/build/demos/Mobiclip/multitrackAudio

コンパイル方法

Cygwin プロンプトから libMobiclip/build/demos/Mobiclip/multitrackAudio ディレクトリに移り、

% make

と入力します。 コンパイルが始まり、実行ファイルである .srl ファイルやバイナリ情報を記述した .nef または .tef ファイルが、

libMobiclip/build/demos/Mobiclip/multitrackAudio/bin/platform/target/

の下に生成されます。例えば、

libMobiclip/build/demos/Mobiclip/multitrackAudio/bin/ARM9-TS/Release/multitrackAudio.srl

が multitrackAudio デモの実行ファイルになります。

実行方法

NITRO ROM の場合

IS-NITRO-DEBUGGER を用いる場合

  • IS-NITRO-DEBUGGER で *.nlf ファイルを読み込んで実行します。
  • IS-NITRO-DEBUGGER で *.srl を実行します。
  • コマンドラインから loadrun.exe で IS-NITRO-DEBUGGER で *.srl を実行します。

IS-TWL-DEBUGGER を用いる場合

  • IS-TWL-DEBUGGER で *.nlf ファイルを読み込んで実行します。
  • IS-TWL-DEBUGGER で *.srl を実行します。
  • コマンドラインから loadrun.TWL.exe で IS-TWL-DEBUGGER で *.srl を実行します。

TWL/NITRO HYBRID ROM の場合

IS-NITRO-DEBUGGER を用いる場合

  • IS-NITRO-DEBUGGER で *.srl を実行します。
  • コマンドラインから loadrun.exe で IS-NITRO-DEBUGGER で *.srl を実行します。

IS-TWL-DEBUGGER を用いる場合

  • IS-TWL-DEBUGGER で *.tlf ファイルを読み込んで実行します。
  • IS-TWL-DEBUGGER で *.srl を実行します。
  • コマンドラインから loadrun.TWL.exe で IS-TWL-DEBUGGER で *.srl を実行します。

TWL LIMITED ROM の場合

IS-TWL-DEBUGGER を用いる場合

  • IS-TWL-DEBUGGER で *.tlf ファイルを読み込んで実行します。
  • IS-TWL-DEBUGGER で *.srl を実行します。
  • コマンドラインから loadrun.TWL.exe で IS-TWL-DEBUGGER で *.srl を実行します。

説明

複数の異なるオーディオトラックを含んだMobiclipムービーを再生する方法を示したサンプルです。
1度に1つのオーディオトラックのみ再生され、再生中はボタンを操作して他のオーディオトラックに切り替えることができます。

・STARTボタンでビデオを一時停止 / 再生
・Bボタンでビデオを停止
・Aボタンでビデオを再生
・SELECTボタンでループを無効 / 有効の切り替え
・L,Rボタンでオーディオトラックの切り替え
・DSカバーを閉じる / 開ける ときにLCDの電源をオフ / オン

動作環境

すべてのサンプルについて、IS-NITRO-EMULATOR と IS-TWL-DEBUGGER での正常動作を確認しています。
