MO_Malloc と MO_Free

構文

#include <nitro/Mobiclip.h>

extern void* MO_Malloc ( u32 size );
extern void MO_Free ( void* mem_p );

説明

割り当て／割り当て解除の関数です。
MO_Malloc および MO_Free は、Mobiclip ライブラリで行われたダイナミック割り当て／割り当て解除を実行します。
MO_Malloc および MO_Free は、Mobiclip ライブラリに実装されていません。外部から宣言されます。
あなたのプログラムに、これらの関数を実装して下さい。
これにより、古典的なmalloc/free関数や、カスタム割り当てルーチンを自在に使うことが可能になります。

MO_Malloc は、MO_OpenMovie と MO_BlitFrameImage 関数によってのみ使用されます。
MO_Free は、MO_CloseMovie 関数によってのみ使用されます。

引数

標準の malloc/free 関数と同じです。

返り値

標準の malloc/free 関数と同じです。
