MO_JumpToIframe

構文

#include <nitro/Mobiclip.h>

u32 MO_JumpToIframe ( MOHandle handle, u32 index );

説明

インデックス指定でI-Frame(キーフレーム)に移動します。

引数

handle 有効なムービーのハンドル。
index ジャンプしたいI-Frameのインデックス。

返り値

エラーがない場合は"1"、ハンドルが MO_INVALID_HANDLE か、あるいはindexが範囲外の場合は"0"。
許可される最大値は MO_GetNbIFrame()-1 です。

MO_JumpNextIframe
